feature heading treatments

The current feature_01 / feature_02 mono index is generic — it numbers rows without telling the reader what kind of thing each row is about. These five proposals each give the three feature rows a distinct visual identity rooted in a different metaphor (terminal tag, world-line letter, drop cap, subject glyph, lab coordinate). Every option still pairs cleanly with the existing terminal-card aesthetic; none of them are numbered.

Option A

Bracketed topic tag

Replaces the index with a short subject word in a bracketed terminal chip. Stays in the existing mono/amber language but each chip names the actual topic, so a reader who glances at one row immediately knows what it covers. Reuses the same bracket motif as the [nav-link] hover state in the navbar.

Option B

World-line Greek mark

A big glowing Greek letter (α / β / γ) stands as the row's identifier, sitting next to a small mono topic label. Borrows directly from Steins;Gate canon (world-line letters α, β, γ, Ω) — fans will recognize it immediately, and the Nixie glow ties it to the divergence-meter rail on the right edge of the section.

Option C

Editorial drop cap

A boxed glowing Latin initial taken from the subject word (S / L / R) leads each heading, magazine-style. Skips ordinality entirely and leans into the editorial pillar of the brand. Pairs well with a small topic label underneath in mono for a published field-note feel.

Option D

Subject glyph + topic

A small one-color SVG icon per topic (book / globe / fork) carries the visual identity, with the subject word right next to it. Most scannable of the five — a user with no Thai literacy can still tell the rows apart at a glance.

Option E

Divergence coordinate stamp

A corner-bracketed stamp showing each feature's "world-line coordinate" — fake-precise divergence values that escalate from 0.337 toward 1.048596 (the canonical Steins;Gate value). Treats each feature as a "checkpoint" on the way to the Steins;Gate ending. Strongest if the rest of the page leans hard into the lab-readout motif.

Recommendation: Option A (bracketed topic tag) is the safest swap — it keeps the existing mono/amber eyebrow chrome and only changes the word inside, so no other section styling needs to move. Option B (world-line Greek) is the strongest brand play and connects directly to the divergence meter; it's the most distinctive but introduces a new typographic element. Options C / D / E are further-out alternatives if a bigger redesign is on the table.
