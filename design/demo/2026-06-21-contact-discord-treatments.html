discord, without the squash

Discord's official widget iframe is a rigid ~350×500 block — its member list has a hard minimum width and never reflows, so beside a content-rich donate column it gets squashed or clipped (and on tablet it becomes a giant blurple slab). The fix: render our own theme-native card from the widget JSON (GET /api/guilds/898151211889475624/widget.json — CORS-enabled, verified live: 282 online, member avatars, fresh invite, 5-min cache). It's fully fluid at any width. Two custom treatments below, plus a no-custom-code fallback that keeps the official iframe but never lets it squash.

Treatment 1 — Recommended

Custom Discord card (widget JSON)

fluid · on-theme · live online count + avatars

Our own card built from the widget JSON: terminal chrome header, server crest + name, a live online count with a stack of member avatars, and an amber Join button. Fluid at any width, short enough to balance the donate column, and it actually looks like it belongs in the lab. Avatars + count refresh client-side on load; if the fetch ever fails it falls back to a static "Join our Discord" card.

Treatment 3

Keep the official iframe — full-width row

zero custom code · iframe never shares a column

The no-build option: keep Discord's real widget but never put it in a narrow column. Give it its own centered full-width row (where it always has its 350px), with the donate column on a separate row below.
