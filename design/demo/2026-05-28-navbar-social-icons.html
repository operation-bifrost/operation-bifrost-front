social icons

Three hover treatments for the social cluster, all mounted on the same navbar shell shipping the nav-link bracket markers chosen in the previous trial. Hover any icon to compare. The amber Join Discord CTA is held constant so you can judge how each treatment plays against it.

01

nixie ignite

Same amber glow language as the nav-link option-1 — icons tint to --color-nixie-base on hover with a faint drop-shadow. Quietest treatment, fully consistent vocabulary.

Icon fills with --color-nixie-base, lifts 1px, gains a soft amber drop-shadow.

Tradeoff
Amber-on-amber-on-amber-CTA in the same cluster — risks visual monotony, especially when hovering near the call to action.
02

brand-color ignite

Same ignite mechanic, but each icon lights to its real brand colour with a matching drop-shadow. Universal recognition cue, chromatic relief next to the amber CTA — without breaking the "fill + glow" hover system.

03

tube-frame

A thin amber square border fades in around each icon on hover, echoing the bordered brand mark (β in a frame). Reads as "selecting a hardware switch on the FGL console."
